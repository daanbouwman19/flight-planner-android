# Freshness manifest for the hand-compiled Filament materials.
#
# `matc` ships only in the Filament release archive, not in the AAR or on any
# developer machine, so the build cannot recompile `*.mat` -> `*.filamat`. This
# manifest lets `:feature:globe:verifyFilamatFreshness` (wired into `check`)
# catch a `.mat` that was edited without its `.filamat` being regenerated, which
# otherwise ships the old shader silently.
#
# After a legitimate recompile:
#   matc --platform=mobile --api=opengl --api=vulkan \
#     -o src/main/assets/materials/<name>.filamat src/main/materials/<name>.mat
#   ./gradlew :feature:globe:updateFilamatChecksums
#   git add src/main/materials/checksums.txt src/main/assets/materials/<name>.filamat
#
# The `matc` line names the Filament release whose matc produced the blobs. A
# .filamat carries a material format version that the runtime refuses to load
# when it differs (Filament 1.76.1 aborted on blobs from 1.75: "Material version
# mismatch. Expected 76 but received 75"), so a runtime bump in
# gradle/libs.versions.toml must come with a recompile from that release's
# archive. verifyFilamatFreshness fails when the two disagree.
#
# Format: matc  <Filament release version>
#         <name>  <sha256 of the .mat>  <sha256 of the .filamat>
